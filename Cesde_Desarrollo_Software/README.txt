Ejemplos Java de consola

Ascensor.java
Simula un ascensor que inicia en el piso 1 y solo sube hasta el piso 24.

Calculadora.java
Realiza suma, resta, multiplicación o división de dos números.

RegistrarCita.java y consultorio.sql
El SQL crea una base de datos y una tabla de citas. El programa Java solicita los datos de una cita y los guarda con JDBC en MySQL.
Para usar el ejemplo de base de datos, ejecute consultorio.sql en MySQL, agregue el controlador JDBC de MySQL al proyecto y cambie usuario y contraseña en RegistrarCita.java.
